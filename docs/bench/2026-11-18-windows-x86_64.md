# Quorix Bench report

- Quorix version: 0.1.0
- Build: release
- System: windows x86_64, 4 logical processors
- Runs for each row: 5
- Tools: Quorix, curl
- File sizes: full

The server runs on this computer. These numbers show the behaviour of each tool under a known server condition.
They are not internet speeds.

How to read the table:

- The time of a Quorix run includes the sync of the file to the disk and the move to the destination.
  Quorix does not report a file as complete before that. The column "Commit ms" shows this part.
- curl and aria2c do not sync the file. Their time ends when the data is given to the operating system.
- Thus a difference in MiB/s on a fast local server is partly a difference in what "complete" means.
- The rows run one after the other on one disk. A row can be slower because the disk is busy with data from the row before it.
